# acp offering

Manage agent offerings.

## Commands

| Command | Description | Optional Flags |
|---|---|---|
| `offering list` | List offerings | — |
| `offering create` | Create a new offering | `--from-file`, `--name`, `--description`, `--price-type`, `--price-value`, `--sla-minutes`, `--requirements`, `--deliverable`, `--required-funds`/`--no-required-funds`, `--hidden`/`--no-hidden`, `--private`/`--no-private` |
| `offering update` | Update an offering | `--offering-id`, plus any field flags |
| `offering delete` | Delete an offering | `--offering-id`, `--force` |

## Examples

```bash
# List offerings
acp offering list --json

# Create from flags
acp offering create \
  --name "Logo Design" \
  --price-type fixed --price-value 5.00 \
  --sla-minutes 60 \
  --requirements '{"type":"object","properties":{"style":{"type":"string"}}}' \
  --deliverable "PNG URL" \
  --json

# Create from file
acp offering create --from-file offering.json

# Update price
acp offering update --offering-id abc-123 --price-value 10.00 --json

# Delete
acp offering delete --offering-id abc-123 --force --json
```
